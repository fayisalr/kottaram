# Kottaram Home Needs - Home Appliances & AI Offer Poster Platform

Official web platform & AI Marketing Studio for **Kottaram Home Needs**, Bank Junction, Alanallur.

## 🚀 Features

- **Customer Appliance Showroom**: Smart TVs, Refrigerators, Washing Machines, Air Conditioners & Kitchen Appliances.
- **AI Offer Poster Studio**: Automatic background removal, multi-line auto-expanding text, 4-way D-pad element position controller, custom sticker tags, and real-time Interactive Canvas Inspector.
- **Staff Portal & RBAC**: Role-based access control with Edit & Delete privileges for Super Admin, Manager, Designer, and Staff roles.
- **WhatsApp Integration**: 1-click offer sharing & WhatsApp customer hub.
- **Supabase SSR Connection**: `@supabase/supabase-js` and `@supabase/ssr` authentication & database helpers.
